= Compatibilidad de ONTAP Select con las funciones de ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ONTAP Select admite la mayoría de las funciones de ONTAP . Muchas de las funciones de ONTAP se licencian automáticamente para cada nodo al implementar un clúster. Sin embargo, algunas funciones requieren una licencia independiente.


NOTE: Las funciones de ONTAP con dependencias específicas de hardware generalmente no son compatibles con ONTAP Select.



[[ontap-features-licensed-by-default]]
[[licensed-ontap-features]]
== Funciones de ONTAP con licencia por defecto

Las siguientes funciones de ONTAP son compatibles con ONTAP Select y están incluidas en la licencia de forma predeterminada.

[cols="1,1,1"]
|===
| Característica | Conoce | Notas 


| Protección autónoma contra ransomware (ARP) | link:https://docs.netapp.com/us-en/ontap/anti-ransomware/index.html["Protección autónoma contra ransomware de ONTAP"^] | ONTAP Select solo admite actualizaciones manuales de ARP. 


| CIFS | link:https://docs.netapp.com/us-en/ontap/smb-admin/index.html["SMB de ONTAP"^] |  


| Deduplicación y compresión | link:https://docs.netapp.com/us-en/ontap-restapi/storage_volumes_endpoint_overview.html["Gestionar volúmenes de almacenamiento"^] |  


| Gestión externa de claves mediante el protocolo de interoperabilidad de gestión de claves (KMIP) | link:https://docs.netapp.com/us-en/ontap/encryption-at-rest/configure-netapp-volume-encryption-concept.html["Activar y configurar la gestión de claves externas"^] |  


| FlexCache | link:https://docs.netapp.com/us-en/ontap/flexcache-writeback/flexcache-write-back-guidelines.html["ONTAP FlexCache escritura diferida"^] | ONTAP Select es compatible con los volúmenes de caché FlexCache con escritura diferida. *Precaución*: existen limitaciones en la escritura diferida de FlexCache con ONTAP Select. Para obtener más información, consulta link:concept_ots_overview.html#flexcache-write-back-with-ontap-select["FlexCache write-back con ONTAP Select"]. 


| FlexClone | link:https://docs.netapp.com/us-en/ontap/volumes/flexclone-efficient-copies-concept.html["Volúmenes FlexClone de ONTAP"^] |  


| ISCSI  a|

La compatibilidad con SVM DR se limita al uso de la versión de ONTAP de origen a las versiones +2. Por ejemplo, el origen de ONTAP Select 9.16.1 puede conectarse a las versiones de ONTAP de destino 9.16.1, 9.17.1 o 9.18.1.

== Funciones de ONTAP con licencias independientes

Debes adquirir una licencia independiente para las siguientes funciones de ONTAP que son compatibles con ONTAP Select, pero no están licenciadas de forma predeterminada.

[cols="1,1,1"]
|===
| Característica | Conoce | Nota 


| FabricPool | link:https://docs.netapp.com/us-en/ontap/concepts/fabricpool-concept.html["ONTAP FabricPool"^] | No necesita una licencia de FabricPool cuando utilice StorageGRID. 


| SDS de MetroCluster | link:reference_plan_ots_mcc_sds.html["MetroCluster SDS para ONTAP Select"] | Se trata de una oferta de licencia premium de ONTAP Select. 


| SnapMirror cloud | link:https://docs.netapp.com/us-en/ontap/concepts/snapmirror-cloud-backups-object-store-concept.html["SnapMirror copias de seguridad en la nube en almacenamiento de objetos"^] | Necesitas link:https://mysupport.netapp.com/site/help["abrir un caso de asistencia no técnica"^] para obtener una licencia cloud de SnapMirror. 
|===
